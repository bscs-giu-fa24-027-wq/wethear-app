# WethearApp — PDF Viewer

A React Native Expo PDF viewer app similar to CamScanner.

## Features
- 📄 **PDF Viewing** — smooth scrolling, pinch-to-zoom, page navigation
- 🏠 **Documents Screen** — list, open, delete imported PDFs
- 📁 **File Manager** — sort by name/date/size, share, delete
- 📷 **Document Scanner** — camera capture + gallery import UI
- 🗂 **Tab Navigation** — Documents / Scan / Files tabs

## Tech Stack
- React Native + Expo (managed workflow)
- expo-router (file-based navigation)
- expo-document-picker (PDF import)
- expo-file-system (local storage)
- react-native-pdf (PDF rendering)
- expo-image-picker (camera/gallery)
- @expo/vector-icons (Ionicons)

## Getting Started
```bash
npm install
npx expo start
```
